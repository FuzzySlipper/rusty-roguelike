# Medieval torch asset

`medieval-torch.glb` is an optimized 512 px texture derivative of
[Medieval Torch - Free](https://sketchfab.com/3d-models/medieval-torch-free-065861234a824cb982764f04627331c9)
by [Typhen](https://sketchfab.com/typhen).

[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).
The model may not be used commercially, attribution is required, and shared
adaptations must use the same license. See `LICENSE.txt` for the bundled notice.

The optimized derivative removes the source scene's unused default objects and
reduces both texture maps from 2048 px to 512 px. It does not change gameplay,
collision, navigation, or authored scene-socket authority.
